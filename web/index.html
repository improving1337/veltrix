Реакции и промпт канала

Настройки сохраняются отдельно для выбранного канала

Цель по реакциям случайно выбирается для каждого нового поста в пределах лимита. Если ❤️ разрешено, оно получает минимум 40%, а в голосовании с ❤️ — больше любого другого варианта.

Просмотры: цель выбирается для каждого поста в диапазоне, заданном в настройках панели, ограничивается доступными аккаунтами и сохраняется между перезапусками.

Каждый уникальный Telegram-аккаунт получает не более одного задания на просмотр и одного на реакцию на каждый пост, даже если подключён под разными именами. Эмодзи реакций перемешиваются по времени с сохранением их количества. Для новостей рекомендации даёт DeepSeek. Для явной рекламы и голосований варианты определяются по тексту и разрешённым реакциям канала. Публикации старше 24 часов не обрабатываются.

Защита аккаунтов

Защита включена по умолчанию для всех подключённых аккаунтов. Другие устройства будут отключены. Уже установленный пароль 2FA не меняется. Новые пароли хранятся только на сервере в security/passwords.json. Если Telegram запретит завершение сессий, повтор состоится через 24 часа. Пауза останавливает следующие проверки.

Загрузка по ссылкам

Поддерживаются Google Drive (файлы и папки) и публичные ссылки MEGA на файлы. Архивы разбираются, из них (в том числе из вложенных папок и tdata) берутся файлы .session и .json, они попадают в Sorting, раскладываются и новые аккаунты сразу подключаются.
